# 📋 To-Do List Life Dashboard

Proyek web sederhana untuk mengatur aktivitas harian, dibuat sebagai tugas **CodingCamp** menggunakan HTML, CSS, dan JavaScript murni (tanpa framework).

---

## 🌐 Live Demo

> _Link GitHub Pages akan diisi setelah deploy._

---

## ✨ Fitur

### MVP (Fitur Wajib)

| Fitur | Keterangan |
|---|---|
| ⏰ **Greeting** | Menampilkan jam, tanggal, dan sapaan otomatis (Pagi/Siang/Sore/Malam) |
| ⏱ **Focus Timer** | Timer mundur 25 menit (Pomodoro) dengan tombol Mulai, Berhenti, dan Ulang |
| ✅ **To-Do List** | Tambah, edit, tandai selesai, dan hapus tugas — tersimpan di Local Storage |
| 🔗 **Quick Links** | Simpan dan buka tautan favorit dalam satu klik — tersimpan di Local Storage |

### Tantangan Tambahan (3 dari 5)

| Tantangan | Status |
|---|---|
| 🌙 **Light / Dark Mode** | ✅ Tersedia — klik ikon bulan/matahari di pojok kanan atas |
| ✏️ **Custom Name in Greeting** | ✅ Tersedia — klik ikon pensil di kartu sapaan |
| 🚫 **Prevent Duplicate Tasks** | ✅ Tersedia — tugas yang sama persis tidak bisa ditambahkan dua kali |

## 🚀 Cara Menjalankan

1. Clone atau download repository ini.
2. Buka file `index.html` langsung di browser — tidak perlu server.
3. Semua data tersimpan otomatis di Local Storage browser.

---

## 📦 Cara Deploy ke GitHub Pages

1. Push repository ke GitHub.
2. Buka **Settings → Pages** di repository.
3. Pilih source: **Deploy from a branch → main → / (root)**.
4. Setelah beberapa menit, website akan tersedia di `https://<username>.github.io/CodingCamp-16November26-Roby/`.
